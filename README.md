# Telco Customer Churn - MLOps Project

This project is organized from the supplied ZIP and Lab 3-6 files.

## Structure

```text
churn-prediction/
├── data/
│   ├── raw/
│   │   └── churn.csv
│   └── processed/
│       └── dataset_metadata.json
├── notebooks/
│   └── project_implementation.ipynb
├── src/
│   ├── preprocess.py
│   ├── train.py
│   ├── evaluate.py
│   ├── preprocess_lab4.py
│   ├── train_mlflow.py
│   ├── evaluate_lab4.py
│   ├── validate_reproducibility.py
│   ├── validate_data.py
│   ├── preprocess_pipeline.py
│   ├── validate_outputs.py
│   ├── train_registry.py
│   ├── automate_lifecycle.py
│   └── generate_registry_report.py
├── pipelines/
│   ├── run_baseline.py
│   ├── run_lab3_baseline.py
│   ├── run_lab4_tracking.py
│   ├── run_lab5_pipeline.py
│   └── run_lab6_registry.py
├── models/
├── outputs/
├── logs/
├── artifacts/
├── requirements.txt
└── .gitignore
```

Generated runtime files are not included in this clean template. They are created by the pipelines.

## Run from the project root

### Lab 3
```powershell
python pipelines/run_lab3_baseline.py
```

### Lab 4
```powershell
python pipelines/run_lab4_tracking.py
```

### Lab 5
```powershell
python pipelines/run_lab5_pipeline.py
```

### Lab 6
```powershell
python pipelines/run_lab6_registry.py
```

Run the labs in order because later labs use artifacts generated by earlier labs.
